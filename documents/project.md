# Общая документация по проекту `opencode`

Это много платформенное Flutter приложение, предназначенное для работы на macOS, Windows, Linux, iOS и Web. Архитектура проекта модульная, с разделением логики, моделей и UI компонентов.

Структура проекта:
- `lib/` — основной исходный код, страницы, модели, утилиты.
- `assets/`, `images/` — графические ресурсы.
- `platform/` — конфигурации для каждой платформы.
- `tests/` — тестовые сценарии.
- `summaries/` — отчеты о сборках.
- `web/` — веб-ресурсы.

Общие рекомендации:
- Используйте `flutter analyze` и `flutter test` для проверки.
- Перед сборкой убедитесь, что все SDK установлены.
- Обновляйте зависимости регулярно.

Для более подробной информации смотрите документацию Flutter и раздел `README.md`.
