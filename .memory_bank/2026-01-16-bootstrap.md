## Установка Bootstrap
- загрузил Node.js 25 через `nvm use stable` (предварительно подключив `~/.nvm/nvm.sh`), чтобы работать в нужной среде
- выполнил `npm install bootstrap@5` внутри `app`, что добавило пакет и обновило `package-lock.json`
- теперь можно подключать `bootstrap/dist/css/bootstrap.min.css` и пользоваться готовыми сетками/компонентами при верстке интерфейса
