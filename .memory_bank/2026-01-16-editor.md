# Редактор изображений 2026-01-16
- Установил `tui-image-editor` через npm и подключил его как модальное окно `ImageEditorModal.vue` с собственным CSS/кнопками сохранения/отмены.
- Передал в `preload.js` и `CaptureService` API `captureScreenshot`/`saveScreenshot`, чтобы сначала показать отредактированный скриншот, а затем сохранить полученный Base64.
- `App.vue` теперь открывает редактор после захвата, отключает прежнее сохранение и добавляет обработчики `handleEditorSave`/`handleEditorCancel`, обновлённые статусы и новые переводы для уведомления пользователя.
