## Поддержка комбинаций на клавиатуре
- теперь `App.vue` настраивает `window.keydown` только после нажатия кнопки «Захватить», ожидает завершения ввода комбинации (включая модификаторы) и сохраняет результат в `settingsForm`, затем показывает сообщение `settings.hotkeyCapturedStatus`
- добавил `cancelHotkeyCapture`, чтобы один слушатель работал только по одному полю и автоматически снимался, плюс очищается во `onBeforeUnmount`
- кнопки «Захватить» по прежнему эмитят событие `capture-hotkey`, которое обрабатывается функцией `handleHotkeyCapture`, привязанной к подобному поведению
