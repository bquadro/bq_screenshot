Добавил debug-режим для глобального контроллера горячих клавиш:

- `GlobalHotkeyController` теперь принимает опцию `{ debug }` и выводит в консоль регистрацию комбинаций только если флаг включён.
- `main.js` создаёт контроллер с `debug: true`, чтобы логировать `Registering global hotkeys: …` в процессе разработки.
