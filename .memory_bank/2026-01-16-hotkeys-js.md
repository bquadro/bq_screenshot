## Использование hotkeys-js
- заменил ручной `keydown` на библиотеку `hotkeys-js`: при нажатии кнопки «Захватить» срабатывает `hotkeys('*', scope, handler)`, а слушатель настроен только на время ввода комбинации
- `attachHotkeyListener` сохраняет предыдущее `hotkeys.filter`, ставит временно функцию `() => true`, назначает scope и регистрирует обработчик, который по `handler.key` (или Escape) записывает комбинацию и снимает слушатель
- функция `cancelHotkeyCapture` теперь снимает бинды через `hotkeys.unbind`, восстанавливает filter и scope, благодаря чему приложение больше не зависает после неудачного захвата
