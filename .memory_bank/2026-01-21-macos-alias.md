# macos-alias 2026-01-21

- проверил сборку `node app/create_dmg.js`, скрипт подхватывает `.zip`, распаковывает и вызывает `electron-installer-dmg`, но внутри `hdiutil` снова зависает из-за отсутствия сконфигурированного устройства (проблема среды);
- при попытке сгенерировать `.dmg` после установки ZIP вылезла старая ошибка `macos-alias`, потому что существующий бинарник `volume.node` был собран для Node 18 (NODE_MODULE_VERSION 108), тогда как текущий Node.js 25 ожидает 141;
- чтобы перейти дальше, нужно использовать `nvm use stable` (Node.js 25), выполнить `npm rebuild macos-alias` или просто `npm install` заново, чтобы native-модуль пересобрался под нужную версию.
