Сделал отдельный класс для IPC-хендлеров:

- `app/src/classes/IpcHandlers.js` содержит регистрацию всех `ipcMain.handle`-запросов (загрузка/сохранение настроек, создание скриншотов, выбор папки, сохранение файла) и работает через `settingsStorage`.
- `app/src/main.js` теперь импортирует `IpcHandlers`, создает экземпляр с `app` и `settingsStorage` и вызывает `.register()`, благодаря чему главный файл вернулся к фокусе на окне и сборке приложения.
- `npm run lint` (скрипт остаётся заглушкой; npm ругается на версию, но команда проходит).
