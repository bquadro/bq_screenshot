Ввёл отдельный контроллер для горячих клавиш:

- Создан `app/src/classes/HotkeyController.js`, обёртка над `hotkeys-js`, которая регистрирует комбинации, снимает их и очищает обработчики.
- `App.vue` теперь использует контроллер: после загрузки/сохранения настроек обновляются шорткаты, при размонтировании происходит очистка, а горячие клавиши запускают существующие действия (скриншоты, запись, настройки).
- `npm run lint` (скрипт по-прежнему выводит «No linting configured», npm сообщает про несовместимость версии).
