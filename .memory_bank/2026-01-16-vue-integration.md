Интегрировал Vue 3 (ES-модули) в рендер-процесс: подключил `vue.esm-browser.js`, переписал `renderer.js` на SPA с `createApp`, сохранил OOP-сервисы для локализации, сохранения настроек и захвата.
- UI теперь описан в шаблоне Vue (кнопка, форма, статусы) и управляется реактивными данными/методами.
- Классы `LocalizationService`, `SettingsService`, `CaptureService` стали чистыми API-обёртками без прямого доступа к DOM, а `renderer.js` работает с ними через Composition API.
- Переводы вынесены в `src/lang`, а HTML теперь только содержит `<div id="app"></div>`; скрипт запускается как ES-модуль.
