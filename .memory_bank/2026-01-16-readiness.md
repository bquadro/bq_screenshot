# Подготовка к работе 2026-01-16
- Приложение на Electron + Vue 3 и Bootstrap, сборка через Forge/Vite, зависимостей: `screenshot-desktop`, `hotkeys-js`.
- Главная логика в `app/src` — `main.js` обрабатывает окна, настройки и сохранение скриншотов, `preload.js` открывает API в рендерере, `renderer.js` подключает Vue.
- Компоненты (`AppHeader`, `HomeActions`, `SettingsForm`) поделены по ответственности, классы `CaptureService`, `SettingsService`, `LocalizationService` инкапсулируют вызовы API и словари.
- Настройки хранятся в JSON-файле по пути `~/.app` и загружаются/сохраняются через `ipcMain`, а интерфейс работает с локализациями `ru/en` и UI-конфигом из `config/ui.js`.
- Горячие клавиши подхватываются через `hotkeys-js`, пока реализован только полный скриншот (с сохранением через диалог) и раскладка placeholder-страниц для записи/области.
