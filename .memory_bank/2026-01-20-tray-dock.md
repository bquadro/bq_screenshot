Добавил управление доком при сворачивании в трей:

- В TrayController появились методы `showDock`/`hideDock`, которые вызываются при показе окна (в том числе по двойному клику и активации) и при его скрытии из трея.
- В `app/src/main.js` события `minimize`/`close` теперь скрывают окно, активируют трей и прячут док (на macOS), а при повторном показе через `activate` снова отображаем док.
- `npm run lint` *(скрипт по-прежнему возвращает «No linting configured»; npm сообщает о несовместимой версии)*.
