# Редактор под размер изображения 2026-01-16
- `ImageEditorPage` теперь хранит `editorWrapperHeight`, вычисляет высоту из `editorInstance.getCanvasSize()` после загрузки, ограничивает по высоте окна и обновляет при ресайзе (`editorWrapperHeight` применяется в `:style`), благодаря чему содержимое редактора по высоте совпадает с картинкой.
- Удалил ненужный `ImageEditorModal`, перевёл отображение редактора на отдельную страницу и оставил только основные кнопки сохранения/отмены, а `updateWrapperHeight` вызывается после загрузки/перезагрузки изображения и при изменении размера окна.
