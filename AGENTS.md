## Назначение  проекта
Программа для съемки скриншотов и записи видео с экрана.

## Реализация
Программа реализована на фреймворке Electron https://www.electronjs.org/ + VueJs 3

Используй NodeJs 25. Для  смены версии используй nvm  use stable

Программа разрабатывается для ОС Windows, MacOs, Linux

Все экраны хранятся в отдельной папке window.
Все методы для работы хранятся в папке classes
Разработка ведется на классах.
Если есть пакет в npm для реализации нужного функционала, то ставим пакет.

## Структура проекта
1. app/src -  все исходники
2. app/src/classes  - классы
3. app/src/lang -  файлы переводов
4. app/src/components - компоненты VueJS
5. app/src/assets - дополнительные файлы (шрифты, иконки и тд)
