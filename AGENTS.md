## Назначение  проекта
Программа для съемки скриншотов и записи видео с экрана.

## Реализация
Программа реализована на фреймворке Electron https://www.electronjs.org/

Используй NodeJs 22. Для  смены версии используй nvm  use stable

Программа разрабатывается для ОС Windows, MacOs, Linux

## Основные функции программы
1. Создание скриншотов
   1.1. Полный экран
   1.2. Область
2. Захват видео
3. Редактор скриншотов
4. Сворачивание в трей
5. Глобальные горячие клавиши
6. Настройка папки сохранения скриншотов
7. Настройка подключения к  S3 хранилищу (Minio)
8. Выгрузка скриншотов в S3 хранилище
9. Хранение настроек в json файле
